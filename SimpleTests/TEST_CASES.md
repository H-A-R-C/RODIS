# RODIS simple test scenarios

## Purpose

This document describes the 48 synthetic scenarios supplied in the `SimpleTests` directory. The scenarios exercise combinations of forward simulation (solving for impacted flow), reverse simulation (solving for unimpacted flow), dam configurations, demand types, climate and flow inputs, bypass rules, winterfill pumping and generated dam networks.

The scenarios provide transparent examples and regression inputs for RODIS. They are deliberately synthetic and should not be interpreted as calibrated representations of real catchments.

## Repository layout

```text
SimpleTests/
├── CommonInputs/              Shared synthetic time-series inputs
├── RunAllScenarios.bat        Runs the available scenarios
├── Scenario01/
│   ├── RODIS\_RunSTEDILegacyVersion\_Scenario01.scn
│   └── RODISOutputs/
├── ...
└── Scenario48/
    ├── RODIS\_RunSTEDILegacyVersion\_Scenario48.scn
    └── RODISOutputs/
```

Each `ScenarioNN` directory contains the scenario definition and the outputs generated by RODIS. Common synthetic time-series inputs are held in `CommonInputs`.

## Scope of the public test data

The public repository includes the synthetic scenario definitions, allowable supporting inputs and RODIS-generated outputs. Private Fortran STEDI reference outputs named `LegacySTEDI\_ScenarioNN.fdy` are not part of the public test dataset.

RODIS-generated `.fdy` files within a scenario's `RODISOutputs` directory are RODIS outputs and are distinct from the private Fortran STEDI reference files.

## Interpreting the paired scenarios

Most scenarios occur as adjacent impacted-flow and unimpacted-flow pairs. The paired structure allows the same underlying dam and input configuration to be exercised in both forward and reverse solution modes.

## Running the scenarios

From the `SimpleTests` directory, run:

```powershell
.\\RunAllScenarios.bat
```

Each scenario writes its generated files to the corresponding `ScenarioNN/RODISOutputs` directory.

## Regression comparison

The automated legacy-STEDI regression test uses the RODIS whole-catchment `.res.csv` output for each scenario. Where separately held Fortran STEDI reference data are available, the test compares that RODIS output with the corresponding `LegacySTEDI\_ScenarioNN.fdy` reference file.

The public scenario root is configured using `RODIS\_SIMPLETESTS\_ROOT`. The private reference root, when available to an authorised user, is configured separately using `RODIS\_STEDI\_REFERENCE\_ROOT`.

## Limitations

* These scenarios test defined combinations of inputs and model features; they do not represent every possible RODIS configuration.
* Successful regression testing demonstrates consistency with the nominated reference behaviour and tolerances, not suitability for every application.
* Users remain responsible for checking input data, assumptions and model suitability for their catchment and purpose.
